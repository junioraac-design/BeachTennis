# Beach Tennis – Placar

Placar de duplas em um único arquivo (`index.html`), sem dependências. Abra no navegador, inclusive no celular.

- Toque no painel da dupla para marcar ponto; **Desfazer** reverte qualquer ponto, game ou set
- Ponto de ouro ou vantagem no 40-40; set único ou melhor de 3
- Tie-break em 6x6 (7 pontos, diferença de 2) com saque correto e aviso de troca de lado
- Saque alternando entre os jogadores da dupla
- Partida salva automaticamente (retoma após fechar a página); cronômetro com pausa
- Atalhos: `1`/`←` dupla 1, `2`/`→` dupla 2, `U` desfazer, `Espaço` pausar
